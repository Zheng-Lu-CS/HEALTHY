# Manuscript Prep Package

本目录汇总了按阶段推进的投稿准备文件，基于 2026-03-14 对项目的重新接管、交叉核对和期刊对标。

当前最重要的结论只有两句：

1. 最稳妥的论文主线不是“照搬最新 `GroupMaskedFT + GMM4` 推荐版”，而是以 `GroupMaskedFT + KMeans + k=3` 作为主模型，`PCA` 作为强基线，`GroupMaskedFT + GMM4` 仅作为高粒度敏感性分析。
2. 原因不是保守，而是证据显示 `GroupMaskedFT + GMM4` 的两个高功能簇几乎按性别分开，若直接当主结果写入正文，审稿风险明显偏高。
