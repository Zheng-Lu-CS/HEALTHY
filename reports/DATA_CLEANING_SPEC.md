# DATA_CLEANING_SPEC

## Missing Encoding (Hard Rules)
- Missing tokens treated as NA: ND, UK, NA, N/A, N\A, N-D, N.D, UNK, UNKNOWN, empty string.
- Literal string "Missing" is NOT treated as NA in raw data; it is a generated category label for categorical imputation.
- Numeric value 0 is treated as valid unless explicitly missing (never converted to NA).

## Missing Handling Strategy (Current Pipeline)
- Columns with missing rate >= 95% are dropped before modeling.
- Numeric features: median imputation.
- Categorical features: Missing kept as its own category (Missing).
- Missingness indicator variables: NOT used in current pipeline.

## Alternative Strategies (Not Implemented)
- Numeric: KNN imputation or model-based reconstruction (masked autoencoder).
- Categorical: mode imputation instead of Missing category.
- Add missingness indicator flags for high-missing features.

## Categorical Encoding Rules
- Encoding: one-hot (dummy variables).
- Low-frequency categories (<0.5%) are merged into 'Other'.
- One-hot naming rule: `<column>=<category>`.
- Region fields (省/市/区): missing -> 'Missing' category.
