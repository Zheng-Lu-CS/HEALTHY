# 深度学习分型主线技术报告

> Note: for manuscript-ready model recommendation, please use `reports/advanced_subtyping/FINAL_RECOMMENDATION_CN.md` as the authoritative final selection. This report remains the full experiment log of the first-pass automatic model selection.

## 1. 工作目标
- 用 `group-aware masked modeling` 升级表格表征。
- 用 `text-table dual-tower contrastive learning` 升级文本路线。
- 与 `PCA-128` 做统一对照，并做严格外部验证。

## 2. 数据与输入
- 样本量：6025。
- 核心输入：59 个核心字段 + 5 个连续化 IC 域分数。
- 最终设计矩阵维度：6025 x 175。
- group-aware 输入分为 9 组：demographics, self_health, cognition, psychological, vitality, locomotion, sensory, disease_burden, lifestyle。
- 文本塔编码器：`bert-base-chinese`。

## 3. 模型设计
### 3.1 GroupMaskedFT
- 把不同临床域切成组 token。
- 随机 mask 约 30% 组 token，仅重建被遮挡组。
- 作用：学习跨域上下文，而不是死记单个变量。

### 3.2 DualTower
- 表格塔初始化为上一步预训练好的 masked encoder。
- 文本塔读取医学化 Tab2Text。
- 训练目标：重建损失 + 0.6 × 对比损失。
- 这一步的目的不是让 LLM 直接替代建模，而是让文本语义和表格语义对齐。

## 4. 聚类评估规则
- clusterer：KMeans 与 GMM。
- k：3–6。
- 指标：silhouette、Calinski-Harabasz、Davies-Bouldin、bootstrap stability、min cluster ratio、external separation。
- 外部验证变量不进入主聚类设计矩阵，只用于验证临床意义。

## 8. 医学意义与 insight
- 在最终模型 `PCA` 中，跨簇差异最大的 IC 维度是 `Locomotion`，提示它是当前样本异质性的主导轴。
- 最差簇与最佳簇形成了清晰梯度：ADL 从 80.2 升至 98.0，IADL 从 14.3 降至 8.8，肌少症评分从 3.66 降至 0.70，Fried 衰弱从 2.16 降至 0.88，跌倒风险从 41.3 降至 25.2。
- 按 Overall IC 排序后，簇序与弹性评分呈正相关（Spearman rho=1.000），提示更好的内在能力与更好的恢复力相伴存在。
- 如果低 IC 簇同时伴随更差 ADL/IADL、更高肌少症、更高 Fried 衰弱与更高跌倒风险，那么这个分型就具备明确的临床意义。
- 如果中间簇在 ADL 尚可时已经出现感官或运动下降，就可以讲‘前失能/早期脆弱化亚型’。

## 9. 论文主故事线
1. 传统 IC 横断面分析容易把复杂功能状态压扁成 0/1。
2. 我们先把 IC 连续化，再把硬编码表格升级成 group-aware token。
3. 再用文本-表格双塔对比学习，把语义层信息拉进来。
4. 最终得到的亚型不仅内部结构更清楚，而且外部 ADL/IADL/肌少症/衰弱/跌倒梯度更明显。
5. 这说明我们捕捉到的不是单纯数学簇，而是具有社区老年临床价值的功能亚型。
