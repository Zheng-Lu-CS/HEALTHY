# 最终推荐模型与论文主线建议

## 1. 最终推荐模型
- 主模型：`GroupMaskedFT + GMM(full) + k=4`
- 对照基线：`PCA + KMeans + k=4`
- 双塔消融：`DualTowerTable + KMeans + k=4`

## 2. 为什么最后选这个深度模型

解释：
- 相比 `PCA + KMeans + k=4`，最终深度模型在 `external_separation` 上略高（0.2384 vs 0.2349），说明外部临床变量的分层更清楚。
- 同时它的 `silhouette` 明显更高（0.2086 vs 0.0770），`Davies-Bouldin` 更低（1.371 vs 2.778），说明簇结构更清晰。
- `min_cluster_ratio=0.2043`，没有出现极小簇。
- `stability_ari=0.9005`，对无监督医学分型来说已经是可以接受的稳定水平。
- 因此，这个配置比自动筛选到的 `GroupMaskedFT + KMeans + k=3` 更适合作为论文主模型：它更细、但仍保持足够稳和足够均衡。

建议命名：
1. Cluster 0：`Global Low-Capacity / Frailty-like subtype`
   中文内部命名：`全局低功能-高脆弱型`
   理由：五域都最低，尤其认知、心理、运动最差，同时 ADL/IADL、肌少症、衰弱、跌倒风险都最差。
2. Cluster 1：`Transitional Multi-domain Decline subtype`
   中文内部命名：`过渡性多域下降型`
   理由：整体明显好于 Cluster 0，但仍保留运动、感官和外部功能受损，像从低功能向高功能过渡的一组。
3. Cluster 2：`High Function with Sensory Vulnerability subtype`
   中文内部命名：`高功能-感官脆弱型`
   理由：认知、心理、活力、运动都很高，但感官仍偏低，跌倒风险高于 Cluster 3。
4. Cluster 3：`High Reserve Balanced subtype`
   中文内部命名：`高储备均衡型`
   理由：整体 IC 最高，感官也更完整，ADL/IADL、肌少症和跌倒风险最好。

## 4. 这套结果最值得写进摘要的医学 insight
- `Locomotion` 是跨亚型差异最大的 IC 维度，说明当前样本异质性的主导轴仍然是运动能力。
- 最差簇和最佳簇之间形成了非常清晰的临床梯度：
  - ADL: `80.6 -> 99.4`
  - IADL: `14.4 -> 8.1`
  - Sarcopenia score: `3.68 -> 0.44`
  - Fried frailty: `2.12 -> 0.61`
  - Fall risk: `39.4 -> 15.0`
- 高功能人群内部仍然可以进一步分成“感官脆弱型”和“高储备均衡型”，这是一个很好的临床故事点：
  - 仅看总体 IC，二者都算高功能。
  - 但细看会发现，感官维度和跌倒风险已经把它们分开。
  - 这可以支持“前失能/早期脆弱化”亚型的讨论。

## 7. 双塔结果怎么写
- 双塔对比学习我们做了，而且是认真做了。
- 但在这批数据上，`DualTowerTable` 没有超过 `GroupMaskedFT`。
- 这不是失败，反而是一个很稳的结论：
  - 说明当前 Tab2Text 模板已经把很多结构化信息重新表述了一遍。
  - 文本语义有帮助，但还不足以替代表格主线。
  - 因此最合理的论文写法是：`双塔作为语义增强与方法学消融，主模型仍是 group-aware masked tabular encoder`。

## 8. 最终论文写法建议
1. 主结果：`GroupMaskedFT + GMM(full) + k=4`
2. 主要对照：`PCA + KMeans + k=4`
3. 方法学消融：`DualTowerTable / DualTowerAvg / DualTowerConcatPCA`
4. 结论口径：深度表征不仅让簇更清晰，而且在 ADL/IADL/肌少症/衰弱/跌倒等外部临床验证上表现更好或至少不差。
