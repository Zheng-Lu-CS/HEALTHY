# 下一阶段方案验证技术报告

## 目标
- 用现有横断面数据验证两条下一阶段路线是否有继续推进价值。
- 方案A：自监督表格表征 + 聚类分型。
- 方案B轻量验证：Tab2Text + 预训练中文文本编码器 + 表格/文本对比学习。

## 本次实际跑了什么
- Baseline 表征：PCA-32。
- 方案A主力表征：Denoising AutoEncoder (32维潜变量，掩码重建)。
- 方案B轻量版：将结构化字段转成中文画像文本，用 `TFIDF+SVD` 编码，再训练表格编码器与文本编码器做对比学习并形成融合表示。
- 每种表示在 k=3..6 之间做 KMeans，对比 silhouette、稳定性 ARI、IC 区分度 eta^2、IC_level 的 NMI。

## 当前最优方案
- 最优表示：`PCA32`
- 最优聚类数：`k=3`
- silhouette：`0.1822`
- stability_ari：`0.9963`
- IC eta^2：`0.2621`
- IC_level NMI：`0.1232`
- Davies-Bouldin：`1.9888`

## 方案B轻量验证结果
- 文本编码器：`TFIDF+SVD`
- 训练集内表格-文本同一样本检索 Top-1 命中率：`1.0000`
- 这是一个对齐诊断指标，只说明两个视图之间存在可学习的一致语义，不应直接当成泛化性能。
- 当前版本还不是完整生成式 LLM 方案，但已经证明“表格转文本再做跨模态学习”这条路可跑通。

## 轨迹尝试
- 在最优表示空间中，从低 IC 受损锚点到高 IC 受损锚点构造了一条横断面伪时序。
- 伪时序与 IC_total 的 Spearman 相关：`rho=0.7502`
- 这不等于真实随访轨迹，但说明 embedding 空间中存在较稳定的“功能退化方向”。

## 结论
- 方案A是当前最适合继续深挖并快速写论文的主线。
- 方案B不建议马上上完整生成式大模型，但值得先做“结构化文本 + 文本编码器 + 对比学习”的过渡版本。
- 伪时序和 prototype counterfactual 都已经有可跑通的最小验证版，可以作为后续 fancy 卖点。
