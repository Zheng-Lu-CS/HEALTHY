# 实验结果详细解读

这一份是把本次真实跑出来的结果翻译成人话。

## 一、我这次到底试了什么

我试了三种表示方式：

1. `PCA32`
   代表“强 baseline”

2. `DAE32`
   代表“方案A 的轻量深度版本”

3. `ContrastiveFusion64`
   代表“方案B 的轻量跨模态版本”

然后对每一种表示都做了：

1. `k=3..6` 的 KMeans 聚类
2. 多指标评价
3. 可视化
4. 与 IC 的关系分析

## 二、方法对比结果怎么看

### 核心结果

当前最好的是 `PCA32 + k=3`

具体数值：

1. `silhouette = 0.1822`
2. `stability_ari = 0.9963`
3. `IC eta^2 = 0.2621`
4. `IC_level NMI = 0.1232`
5. `Davies-Bouldin = 1.9888`

`DAE32` 也不差，但整体还是略逊于 `PCA32`。

`ContrastiveFusion64` 说明跨模态路线可跑通，但目前还不够稳。

### 这说明什么

第一，不要把“深度学习”本身神化。

真实情况是：
如果深度模型结构不够适合表格数据，它不一定比强 baseline 好。

第二，方案A仍然值得做。

因为这次不是说“深度表征完全不行”，而是说：
“简单版 DAE 还不够强，下一步要换更适合 tabular 的自监督架构。”

第三，方案B要谨慎推进。

当前轻量跨模态路线还不够成熟，但作为辅助增强层是有价值的。

## 三、训练曲线说明了什么

### DAE 损失

DAE 重建损失从：

`0.1968 -> 0.0648`

说明模型确实学到了数据重建能力。

但“重建得好”不等于“聚类结构一定更好”，这就是为什么最后它没超过 PCA。

### 对比学习损失

对比学习损失从：

`3.0844 -> 0.0337`

说明表格视图和文本视图之间，模型能学到一致性。

但同样地：
“对齐成功”不等于“下游 cluster 一定最好”。

所以我们要把它当成一条可发展的路线，而不是直接说“多模态就是最强”。

## 四、最佳聚类结果怎么理解

### 最优 cluster 数

当前最优是 `k=3`

三个 cluster 的样本数分别是：

1. `cluster 0 = 3498`
2. `cluster 1 = 1452`
3. `cluster 2 = 1075`

### 各簇的 IC 画像

三个簇在 IC_total 上的均值分别是：

1. `cluster 0 = 1.91`
2. `cluster 1 = 2.04`
3. `cluster 2 = 3.66`

这很清楚地说明：

1. `cluster 0`
   可以理解成“中低风险型”

2. `cluster 1`
   可以理解成“中风险过渡型”

3. `cluster 2`
   可以理解成“全域受损更重的高风险型”

### 五域层面的图像

`cluster 2` 在五域上都明显更差：

1. `IC_sensory = 0.82`
2. `IC_vitality = 0.60`
3. `IC_locomotion = 0.99`
4. `IC_cognition = 0.68`
5. `IC_psychological = 0.57`

这说明它不是单一受损型，而更像“全域受损型”，尤其是运动域最突出。

## 五、伪时序结果怎么讲

这是本次比较亮眼的结果之一。

### 做法

我在最佳 embedding 空间里，找了一个“低受损中心”和一个“高受损中心”，然后看每个人沿这条方向走了多远。

### 结果

这个伪时序分数和 `IC_total` 的相关是：

`rho = 0.7502`

### 怎么解读

这说明：
虽然我们没有随访，但在表征空间里，确实存在一条比较明显的“功能退化方向”。

### 怎么讲得严谨

你要强调：

1. 这不是纵向随访轨迹
2. 但它是横断面数据中一个稳定的连续排序
3. 它可以和 cluster 形成互补：
   cluster 负责“分类”
   pseudotime 负责“排序”

## 六、counterfactual 结果怎么讲

这次我做了两层：

### 第一层：样本级 prototype counterfactual

做法是：

1. 从最差 cluster 里找代表样本
2. 去最健康 cluster 里找最近的原型样本
3. 看两者最主要差在哪些变量

这一层更适合展示概念，不适合做太强的医学解释。

### 第二层：簇间方向差异

这个更稳，也更适合汇报。

如果从最差 cluster 向最健康 cluster 靠近，变化最大的方向是：

1. `运动-总分` 明显更高
2. `心理-总分` 明显更低
3. `认知-总分` 明显更高
4. `活力-总分` 更高
5. 年龄更低
6. 脑血栓比例更低
7. 药物数量更少
8. 慢病数量更少
9. 住院和急诊次数更少

### 这里要注意一个坑

`生活行为与社会功能评估-总分` 在当前结果里方向看起来有点反直觉。

这说明两种可能：

1. 这个量表的编码方向和我们直觉相反
2. 或者总分里不同维度混在一起，不适合直接粗暴解释

这类变量在正式论文里必须回到 codebook 再核对方向。

这个点你最好主动说出来，会显得你很严谨。

## 七、这次结果支持什么，不支持什么

### 支持的

1. 现有数据里存在稳定的亚型结构
2. 方案A是合理主线
3. 伪时序是值得继续做的卖点
4. 表格转文本再做跨模态学习这条路能跑

### 目前还不支持的

1. 不能说方案B已经成熟
2. 不能说现在的 DAE 就比传统方法更强
3. 不能把伪时序说成真实疾病进展
4. 不能把 counterfactual 说成干预因果

## 八、最适合你在汇报里说的那句总结

我这次做完之后的判断不是“深度学习一定更强”，而是：

在我们这批横断面数据上，`高维无监督表征学习 + 分型 + 伪时序` 这条主线是成立的；但如果要发 A 类，深度模型必须从“简单 AE”升级到真正适合表格数据的自监督架构，而 LLM 更适合作为文本视图和解释增强层接入。
