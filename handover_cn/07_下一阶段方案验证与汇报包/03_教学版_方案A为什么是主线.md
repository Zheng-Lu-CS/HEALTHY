# 教学版：方案A为什么是主线

这一份是写给“知道深度学习大概是什么，但对统计和机器学习术语不熟”的版本。

## 先说一句人话

方案A的核心不是“做一个模型去预测什么标签”，而是：

把 361 维又杂又乱的调查数据，先压成一个更有结构、更容易理解的低维表示，再在这个表示空间里找出老人群体里自然存在的几类亚型。

这件事很适合你们现在的数据，因为：

1. 你们没有随访
2. 你们没有未来结局标签
3. 但你们有很多维度的横断面信息

所以现在最合理的问题不是“预测未来”，而是“发现现在这批人内部有哪些稳定结构”。

## 方案A的整条流程

### 第一步：把原始表格整理成模型能吃的矩阵

输入是什么：

1. 原始 Excel
2. 每个样本 361 列
3. 既有数值，也有类别，也有缺失

做了什么：

1. 统一缺失值
2. 类别变量映射成人能看懂的含义
3. 数值标准化
4. 类别变量 one-hot

输出是什么：

一个纯数值矩阵，行是样本，列是模型输入特征。

你可以把它想成：
把“各种风格不同的调查字段”，统一翻译成同一种数学语言。

## 第二步：表征学习

### 1. PCA 是什么

PCA 可以理解成：
“在不看标签的情况下，找出数据里最主要的几个变化方向。”

它解决什么问题：

原始维度太高、太杂，看不清结构。PCA 帮我们先压缩。

输入：
高维特征矩阵

输出：
每个样本一个低维向量，比如 32 维

你可以把它想成：
把 361 个问题的复杂回答，压成 32 个“综合坐标”。

### 2. DAE 是什么

DAE 是 `Denoising AutoEncoder`，中文可以叫去噪自编码器。

它解决什么问题：

PCA 只能做线性压缩，而现实里很多关系可能是非线性的。DAE 想学到更复杂的结构。

它怎么做：

1. 先把输入数据故意弄脏一点，比如随机遮住一部分特征
2. 让模型根据“带缺失的输入”去还原原始输入
3. 模型在这个过程中，必须学会一个比较有用的隐藏表示

输入：
高维特征矩阵

输出：
每个样本一个低维潜在向量

你可以把它想成：
老师故意把一份表格涂掉一部分，让模型学会“根据上下文把信息补回来”，这样模型就被迫理解数据结构。

### 3. 为什么这次 DAE 没有打赢 PCA

这次真实结果里，`PCA32` 比 `DAE32` 略好。

这不代表深度学习没用，而更可能说明：

1. 当前这版 DAE 太简单
2. 表格数据不是图像，普通 MLP-AE 不一定合适
3. 你们的数据 one-hot 后线性结构已经不弱

所以正确结论不是“那就不要深度学习了”，而是：
“如果要继续走方案A，就应该换更对路的 tabular 深度模型。”

## 第三步：聚类

聚类就是：
不告诉模型答案，让它自己把相似的人分到一组。

### KMeans 是什么

KMeans 可以理解成：
“先假设有 K 个中心点，然后把每个人分给最近的中心。”

输入：
每个样本的低维表示

输出：
每个样本属于哪个 cluster

为什么要聚类：

因为我们想知道这 6025 个老人里，自然能分成几种不同的功能状态亚型。

## 第四步：怎么判断聚类好不好

这一步很重要，因为无监督学习没有标准答案，所以不能只看一张图好不好看。

### 1. silhouette

它问的是：
“每个样本更像自己簇里的人，还是更像别的簇的人？”

越大越好。

### 2. stability ARI

它问的是：
“如果我换随机种子重新聚类，结果还稳不稳？”

越高说明越稳。

### 3. IC eta^2

它问的是：
“这个聚类结果，能解释多少 `IC_total` 的差异？”

简单理解：
如果不同 cluster 的 IC_total 差得很明显，那说明这个聚类和功能状态是有关系的。

### 4. NMI

它问的是：
“cluster 和已有的 `IC_level` 分层，是不是有一定一致性？”

越高说明 cluster 不是乱分的。

## 第五步：伪时序是什么

这次我们额外做了一个很有意思的尝试：`pseudotime`

这个词不要怕，它其实可以理解成：

“虽然我们没有随访，但能不能在 embedding 空间里找到一个从相对健康到相对差的连续方向？”

输入：
每个人的 embedding

做法：

1. 找相对健康的人群中心
2. 找相对高风险的人群中心
3. 看每个人在这条方向上走了多远

输出：
每个人一个 `0 到 1` 的分数

意义是什么：

它不是“真实时间”，但能帮助我们把“亚型”之外再补一个“连续退化轴”。

这次结果里，伪时序和 `IC_total` 的相关有 `0.7502`，说明这个连续方向是有意义的。

## 第六步：为什么方案A仍然是主线

因为它最适合你们现在的数据约束：

1. 不需要未来标签
2. 不需要随访
3. 能同时兼顾：
   `分型`
   `风险轴`
   `解释`
   `可视化`

## 下一步如果继续做方案A，应该升级什么

不是简单地“多训几轮”，而是：

1. 把 `DAE` 升级成更适合表格的 `FT-Transformer` 或 `SAINT`
2. 做按语义组的掩码，而不是随机逐列掩码
3. 加入多视角一致性，比如表格视图和文本视图对齐
4. 把伪时序和 cluster 同时作为结果层

## 你如果要用一句最简单的话向学长解释方案A

方案A做的事情就是：
先把很乱的表格数据学成一个更聪明的低维表示，再在这个空间里找出老人群体的自然亚型和退化方向。
